Read it at a glance

        
Four states. You learn them in a minute.

        
Boxbox listens to each agent's own hook events, so the icons change the moment the agent does.

      

      

        
Running
A comet circles the icon. Triggered by UserPromptSubmit and tool use.

        
Needs you
Amber glow and a question mark. A permission request or a question is waiting.

        
Done
Mint ring with a check. The answer from Stop is ready and you haven't looked yet.

        
Subagents
A blue number on the icon. That's how many subagents this session is running.

What it does

        
Stop hunting through tabs.

      

      

        
Jump
The exact pane, not just the app
A click lands on the right iTerm session, tmux pane, WezTerm tab or editor terminal. ⌥⌘J takes you to whoever is waiting, Esc stops a run in a background tab.

        
Permissions
Allow from the edge of the screen
Allow, Always or Deny for Claude Code in the hover card. If you're already in that terminal, Claude asks there as usual.

        
App
Everything in one window
Overview, every live session with its history, and a resume button that reopens it in claude, copilot or codex.

        
Changes
+120 −34 · 5 files
Uncommitted changes per session, one click to the diff or your editor's source control.

        
Usage
Every plan limit in one place
Claude's and Codex's 5-hour and weekly windows, Copilot's premium requests, context fill per session, and what Claude's tokens would cost via the API.

        
Recap
Your week with your agents
Prompts, agent time, tokens and cost per project, compared with the week before. Every Monday morning.

Questions

        
Before you ask.

      

      

        
Is this made by Anthropic, GitHub or OpenAI?
No. Boxbox is an independent app that works with each agent through its public hooks. It isn't affiliated with or endorsed by Anthropic, GitHub or OpenAI.

        
Does my code leave my Mac?
No. The app only listens on 127.0.0.1 and keeps everything in your Library folder. It goes online for the update check and, if you use Copilot, to read your premium requests from GitHub.

        
Will it slow my agent down?
No. The hook runs in the background with a one-second timeout. If the app isn't running, your agent carries on as if it weren't installed.

        
Which agents does it support?
Claude Code, GitHub Copilot CLI and Codex CLI today. OpenCode and Gemini CLI are next; tick yours in the waitlist form so we know.

        
Which Macs?
macOS 14 Sonoma or later, Apple silicon and Intel.

        
Does it work with several screens?
Yes. The bar follows the screen with the active window, or stays on your main screen if you prefer.
